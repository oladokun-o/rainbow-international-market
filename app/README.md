# app

The SvelteKit application for Rainbow International Market. See the
[repository README](../README.md) for the project overview, stack, and the
full commands table.

```bash
cp .env.example .env   # fill in real values — .env stays in this folder
npm install
npm run dev
```

| Command | What it does |
|---|---|
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Production build (emits `.vercel/output/`) |
| `npm run preview` | Preview the production build locally |
| `npm run check` | `svelte-kit sync` + `svelte-check` type checking |
